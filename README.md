# UniHub — UH Brand Integrated

Open `index.html`.

This build preserves the current UniHub functionality and adds:
- approved UH monogram branding
- dark/light logo variants
- favicon/app mark
- consistent purple/blue/magenta palette
- reusable SVG line-icon system
- redesigned homepage hero/banner
- mouse-follow 3D hub movement
- branded feature cards
- branded login, signup and onboarding
- branded logged-in navigation

Brand assets are inside `assets/`.


## Individual icon pictures
All UI icons are now stored as separate SVG image files inside:
`assets/icons/`

Generated 17 separate icon pictures.
The HTML references these files directly with `<img>` tags.


## PNG icon assets
The UI icon set is now exported as 17 transparent PNG image files
at 128×128 px inside `assets/icons/`. The website references the PNG files directly.


## PNG brand assets
The remaining UniHub brand files are now real PNG images:
- `assets/favicon.png`
- `assets/logo-dark.png`
- `assets/logo-light.png`
- `assets/logo-mark.png`

The HTML has been updated to reference these PNG files directly.
